# 双仓库只读预览

这是单独的测试程序，不是完整的 Skills Manager 安装包。

1. 启动程序，展开仓库来源。
2. 分别添加两个仓库，为它们取容易区分的名称；按仓库实际情况填写分支和技能目录。
3. 对每个仓库点击刷新，查看 Git 中已提交的技能目录。

程序不会发布仓库、接收或执行远程部署指令。它不展示两台电脑的实时技能库或 Agent 部署情况；两台机器尚未同步的本地改动不会出现在仓库快照中。它也不提供技能更新或分发。

预览使用临时数据库，正常退出后清理；异常退出可能留下临时文件。访问仓库会调用本机 Git 和 SSH，使用它们现有的配置和认证方式。不要在仓库地址中填写密码或令牌。访问私有仓库需要已有读取权限。

为避免遍历非普通文件，仓库技能目录树包含符号链接或子模块时可能拒绝刷新并保留上次结果。若出现该情况，请记录错误，不要直接改动仓库。
